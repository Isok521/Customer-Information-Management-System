# 纸质问卷电子化与手动录入

2026-09-14更新。参考用户提供的《问卷（德汇康）(1).docx》，读取全部正文；原Word文件未修改，也未上传。

## 字段对应

| 原问卷内容 | 电子字段及行为 |
| --- | --- |
| 接待人员、体验项目、姓名、性别、电话、填表日期 | 独立录入；接待人员和体验项目均可自定义 |
| 1. 年龄区间 | 保留25–30、31–40、41–50、50岁以上原选项；另可补充实际年龄 |
| 2. 症状 | 原14项逐项多选，另存其他症状；未勾选不自动解释为无症状 |
| 当日测量 | 收缩压、舒张压、心率独立数值；空白为null |
| 3. 养生方式 | 原4项可多选，完整保留选项说明 |
| 4. 消费观念 | 原3项选项，另含未填写 |
| 5. 接收资讯、沙龙通知 | 愿意、暂不需要、未填写；只记录，不发送通知 |
| 6. 个人养护诉求 | 每年体检、异常指标、急于解决症状及说明、运动频率、补充诉求 |
| 7. 知晓渠道 | 来源词条多选+其他渠道；词条可增加、移除，历史答案按文字快照保留 |
| 设备禁忌 | 原7条逐项核实：未核实、有此情况、已核实无此情况；另存备注 |
| 注意事项 | 全部9条原文可见 |
| 客户确认、签名及日期 | 展示确认原文；记录阅读确认、纸质签署状态、签名姓名照录、日期及留存备注 |

纸质原件第2题未显示序号，电子表单按顺序补为第2题；其余题目含义不改变。设备告知与客户确认文字只是原文展示，不作为对医疗适用性或法律效力的判断。姓名照录不是电子签名。

创建后在客户详情“健康档案”逐项回看，通过“编辑客户资料 / 问卷”修改原档案，不另建重复客户。

## 自定义来源

在新增或编辑客户的第7题展开“管理来源词条”。初始词条取自纸质问卷：抖音、朋友介绍、官方网站、公众号。支持添加和移除、去除首尾空白、防止重名；已选历史来源不会随着词条被删除而丢失。“其他渠道”可照录自由文字。

## 套餐权益

套餐页和客户权益Tab均有新增入口。支持选择所属客户，自定名称、包含项目、购买日期、金额、总次数、有效期、状态。已有套餐可编辑；客户归属不能改动，关联服务的项目/日期不能被编辑排除。

“录入前已使用次数”表示系统启用前已消费的次数，不生成虚假的历史服务。剩余=总次数−录入前已用−系统使用流水。已有系统使用流水时不能修改录入前已用值，总次数不能低于已用次数。

新建服务可自由填写实际项目，也可从客户套餐项目中选择。员工按实际姓名填写，不再依赖虚构技师名单。

## 演示数据迁移

运行时不再导入Mock。新浏览器客户、健康档案、服务、套餐、跟进和员工为空。旧localStorage的v1会一次性迁移到v2：只移除预置c-1至c-6客户及其关联记录，包含上次验收加在预置客户下的服务；保留后来以新ID手动录入的客户、问卷和关联权益。
